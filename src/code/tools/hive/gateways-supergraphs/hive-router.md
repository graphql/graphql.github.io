[Hive Router](https://the-guild.dev/graphql/hive/docs/router) is a fully open-source, MIT-licensed [GraphQL federation](https://the-guild.dev/graphql/hive/federation) router built in Rust for speed and low resource usage.

It runs a federated supergraph and supports Apollo Federation v1 and v2 schemas. You can run it on its own or connect it to [Hive Console](https://github.com/graphql-hive/console) for schema registry, usage reporting and persisted documents.
